# خطة تنفيذ إصلاحات مراجعة WO-20

المصدر: `docs/reviews/REVIEW-2026-10-26-AR.md` والتحقق منها `docs/reviews/REVIEW-2026-10-26-VERIFICATION-AR.md` (32 ملاحظة، كلها ثابتة).
التاريخ: 2026-10-29. التنفيذ مستقل بتفويض المالك: فحص، دفع، دمج، نشر بـ`update.sh`، فحص الإنتاج، تقرير ختامي.

## قواعد التنفيذ

- أمر عمل لكل مستوى، فرع لكل أمر (`wo/32-…`)، PR بعنوان الأمر وقائمة القبول والأدلة (CLAUDE.md 24).
- لا دمج قبل أن تكون الفحوص التسعة خضراء؛ لا إضعاف ولا تخطي لاختبار (قاعدة 21).
- كل قرار ناقص يُنفّذ خلف إعداد مسمّى بقيمة افتراضية موثقة ويُسجَّل في BACKLOG (قاعدة 28)، وكل تغيير تصميمي في DECISIONS.
- النشر بـ`infra/update.sh <commit>` (لا `git pull` ثم `update.sh`، بسبب D-02)، ثم فحص الإنتاج.
- هذا الملف هو مرجع التقدم: تُعلَّم البنود عند إنجازها.
