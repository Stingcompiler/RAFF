# مدخلات صفحات الهبوط — ما ينتظر المالك

تُملأ هذه القوائم ثم تُنقل القيم إلى مواضعها. **لا يُختلق شيء:** ما لا يُعرف يُكتب «لاحقاً» ويبقى موسوماً `[دليل: …]` غير منشور (LANDING §2). الحالة بتاريخ 2026-10-24: كل الحقول فارغة.

## 1. بيانات الثقة للمتجر (BACKLOG 139)

تُقرأ من `PROJECT_PROFILE.yaml › market` وتُعرض بالترتيب في «الثقة» وفي الـ footer.

| الحقل                                                                    | القيمة | يُعرض في                        |
| ------------------------------------------------------------------------ | ------ | ------------------------------- |
| `trust_values.regulator` — الجهة والرقم (مثل الجهة المانحة ورقم الترخيص) |        | الثقة، الـ footer               |
| الاسم القانوني للكيان (`legal_entity`)                                   |        | الـ footer                      |
| `commercial_registration` — السجل التجاري (إن وُجد)                      |        | الـ footer                      |
| `payment_methods` — بأسمائها كما يعرفها الزبون                           |        | قرب الإجراء                     |
| رقم واتساب الحقيقي (`contact_value`)                                     |        | الإجراء الثانوي والشريط المثبّت |
| العنوان وساعات العمل الحقيقية                                            |        | الـ hero، تواصل، الـ footer     |

بعد الاستلام: تُحدَّث إعدادات المتجر في النظام (لا في الكود)، ويُملأ `market.trust_signals` بالترتيب، ويُزال تنبيه «بيانات تجريبية» عن الـ footer.

## 2. صفحة التعريف `/ar` `/en` برَفّ (BACKLOG 141)

| الحقل                                                                              | القيمة |
| ---------------------------------------------------------------------------------- | ------ |
| `type` و`goal` (برمجي · تجربة / خدمة · استشارة …)                                  |        |
| `headline` عربي (≤10 كلمات: ماذا يفعل رَفّ ولمن)                                   |        |
| `headline` إنجليزي (بلا ترجمة آلية)                                                |        |
| `subhead` عربي وإنجليزي (≤20 كلمة)                                                 |        |
| `cta_label` — صيغة واحدة تتكرر                                                     |        |
| قناة التواصل ورقمها/عنوانها                                                        |        |
| الأدلة المسموح بنشرها: شعارات، عدد عملاء، شهادات (اسم + صفة + مدة أو رقم + موافقة) |        |
| قسم أسعار؟ (ظاهر / عند الطلب / مخفي)                                               |        |
| `network_budget` (low ≤500KB كالمتجر؟)                                             |        |

الأقسام تُبنى بترتيب §1 من LANDING.md لنوعها؛ كل قسم بلا دليل يُحذف أو يُترك موسوماً.
